# v2.2.0 发布说明

`v2.2.0` 增强空间扫描结果输出，重点加入概览报告、三维拼接索引和列优先蛇形路径，方便后续对 XY + Z 图像序列做离线拼接与追溯。

## 变更

- 概览扫描结束后生成 `概览扫描报告.txt`，记录网格、重叠率、标定矩阵、瓦片目标 / 实际 DPOS、XY 误差和图像路径。
- 空间纵向扫描新增 `三维拼接说明.txt`，说明 XY 路径、网格、Tile 视场、PZT 扫描参数和拼接数据使用方式。
- 空间纵向扫描新增 `acquisition/三维拼接索引.csv`，逐图记录 tile、row/column、实际 X/Y/Z 坐标、raw/corrected 类型和相对图像路径。
- 三维拼接索引可区分 raw 与 corrected 图像，启用校正输出时会分别记录。
- 空间路径新增 `蛇形-列`，支持列优先蛇形扫描，适配不同样品方向和运动策略。
- UI 路径选项调整为 `蛇形-行`、`蛇形-列`、`单向`。
- 补充概览报告、三维拼接索引、raw/corrected 索引和列优先路径测试。

## 已知限制

- 三维拼接索引记录视野中心和轴对齐视场尺寸，不包含逐像素旋转 / 剪切仿射矩阵。
- 精确像素级拼接仍应结合相机-位移台标定和图像配准。
