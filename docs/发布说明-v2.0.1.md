# v2.0.1 发布说明

`v2.0.1` 是 `v2.0` 后的空间扫描修正版，重点修正 XY 绝对 DPOS、拼图坐标和相机方向相关问题。

## 变更

- 空间地图改为 X 向右、Y 向上的样品坐标显示，和控制器绝对 DPOS 方向保持一致。
- 概览扫描和空间扫描完成后，会移动并停在用户设置的终点 DPOS；中止任务不会额外移动。
- 实时拼图使用控制器实际 DPOS 作为每张瓦片的视野中心，目标点只作为规划参考。
- 拼图配准只允许在 DPOS 先验附近做小范围残差修正，避免周期纹理造成大跳变。
- 空间规划界面显示实际有效重叠率，并支持隐藏 / 显示瓦片边框。
- 水平镜像加入默认校正逻辑，UI 复选框表示在默认校正基础上额外反转。
- 删除仓库根目录中的旧 UI 预览 PNG，减少无关演示图片对项目体积和版本差异的干扰。
