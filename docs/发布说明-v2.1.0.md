# v2.1.0 发布说明

`v2.1.0` 继续完善 XY 空间扫描流程，重点改进样品地图交互、概览取帧时序、拼图配准方向和低重叠率扫描规划。

## 变更

- 样品地图从主界面 Tab 改为独立非模态窗口，空间扫描运行中关闭地图会先提示是否停止扫描。
- 样品地图新增两点测距功能，可直接显示 `ΔX`、`ΔY` 和直线距离。
- 概览扫描改为连续采集新帧屏障：位移稳定后丢弃首张在途帧，再保存第二张新帧，降低旧位置图像误绑定到新 DPOS 的风险。
- 软触发采集前清理 SDK 缓存，并只接受明确标记为触发帧的新图像。
- 空间扫描中的逐瓦片纵向采集固定使用软触发，避免普通扫描入口的触发模式串入空间扫描。
- 空间规划重叠率范围调整为 5%–10%，规划步距固定按设置重叠率推进，减少不必要的重复采集。
- 拼图配准修正 phase correlation 残差方向，并继续限制为 DPOS 先验附近的小范围修正。
- 标定流程增加 XY 对角点闭合校验，用于拒绝周期纹理造成的错误匹配。
- 补充相机新帧屏障、测距、地图窗口、低重叠率规划、配准方向和空间扫描 Worker 测试。
